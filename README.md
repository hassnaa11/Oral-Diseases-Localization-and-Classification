Oral Diseases Localization and Classification System

This project is an AI-powered system that uses computer vision to detect oral diseases quickly and accurately. Users can upload a photo of their mouth, which is instantly analyzed to identify potential oral health issues. The system visually highlights affected areas using localization techniques based on the YOLOv11 model, helping users clearly understand the detected condition. It classifies images into four categories—caries, ulcers, gingivitis, and discoloration—using a ConvNeXt model, and provides actionable recommendations or early alerts to support timely diagnosis and treatment.
